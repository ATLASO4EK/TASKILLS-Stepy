# Stepy

**Stepy** — веб-приложение для создания и прохождения пошаговых инструкций. Пользователи могут публиковать собственные руководства, выполнять их по шагам и отслеживать прогресс.

## Возможности

- Регистрация и вход по email и паролю.
- Каталог инструкций с поиском по названию и описанию.
- Фильтры «Все» и «Мои».
- Создание и редактирование собственных инструкций.
- Добавление, удаление и изменение порядка шагов; к шагам можно прикреплять изображения.
- Прохождение инструкции с отметкой выполненных шагов и индикатором прогресса.
- Создание копии инструкции (**fork**) для дальнейшего редактирования.
- Интерфейс на русском и английском языках.

## Технологии

**Frontend:** HTML, CSS, JavaScript, Bootstrap 5.3.3.

**Backend:** Python, FastAPI, SQLAlchemy (асинхронная работа с БД), Pydantic, JWT.

## Локальный запуск

### 1. Backend

В `src/.env` укажите параметры подключения к базе данных и секретный ключ для JWT:

```env
DATABASE_CONN_STRING=строка_подключения_к_БД
SECRET_KEY=секретный_ключ
```

Файл `req.txt` сохранён в UTF-16. При необходимости сначала преобразуйте его в UTF-8:

```bash
python -c "from pathlib import Path; Path('requirements.txt').write_text(Path('req.txt').read_text(encoding='utf-16'), encoding='utf-8')"
```

Установите зависимости и запустите сервер из корневой папки проекта:

```bash
python -m pip install -r requirements.txt
uvicorn src.main:app --reload --host 127.0.0.1 --port 8000
```

После настройки подключения создайте таблицы БД запросом `POST` на адрес:

```text
http://127.0.0.1:8000/setup_database
```

### 2. Frontend

Из корневой папки проекта запустите локальный статический сервер:

```bash
python -m http.server 8001
```

Откройте в браузере `http://127.0.0.1:8001/index.html`.

Frontend отправляет запросы к API по адресу `http://127.0.0.1:8000` — он задан в `js/api.js`.
